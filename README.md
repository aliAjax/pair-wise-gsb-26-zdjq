# hxwl-12 心理咨询个案记录 · 练习跟进台

替代纸卡的家庭练习跟进：登记练习说明与核查日，按天收集分钟数、难度和卡点，未达标自动进入待讨论，连续漏交进入回访名单。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 分层结构

资料、判断、本机保存、页面四层分开实现：

- `src/data/` 资料层：类型定义（`types.ts`）与演示数据（`seed.ts`，相对今天生成）
- `src/domain/` 判断层：纯函数，不碰页面也不碰存储
  - `practice.ts`：登记防重叠、每日提交判定、调整留痕、漏交与回访名单
  - `dates.ts`：本地时区日期工具
- `src/storage/localStore.ts` 本机保存层：localStorage 读写，损坏时回退演示数据
- `src/ui/` + `src/App.tsx` 页面层：个案卡片、三个表单、待讨论与回访面板

## 业务规则

- **登记练习**：练习说明、每日目标分钟、开始日、核查日；同一个案的练习期 `[开始日, 核查日)` 不得重叠，核查日前不能安排第二项
- **每日提交**：实际分钟、难度（1-5）、卡点；未达目标分钟或难度 ≥ 4 → 待讨论，不算完成；当日不可重复提交，不可提交未来日期
- **调整留痕**：调整必填原因，原内容与原因进入调整历史，永不覆盖
- **回访名单**：练习期内连续漏交 ≥ 2 天的个案自动进入；补交后自动移出
- **待讨论结案**：会谈中讨论后可标记「已讨论」并记录结论

## 数据保存

所有数据保存在本机浏览器 localStorage（键：`hxwl12.practice.v1`），刷新不丢失；页头可一键重置为演示数据。
