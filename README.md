# hxwl-12 心理咨询个案练习跟进台

为每个个案登记家庭练习，按天跟进实际分钟、难度与卡点，会谈前一屏看清练了几天、卡在哪里。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 功能

- **练习登记**：练习说明、每日目标分钟、开始日、核查日；同一个案在已有练习的核查日前不能重叠安排第二项
- **每日提交**：按天提交实际分钟、难度（1-5）和卡点；未达目标分钟或难度 ≥ 4 的记录进入「待讨论」，不计入完成；同日重复提交覆盖旧记录
- **调整留痕**：调整练习时必须填写原因，原内容快照与原因一起保留在调整历史中
- **回访名单**：连续两天漏交自动进入回访名单，侧栏和指标卡同步提示
- **本机保存**：所有练习与提交记录保存在浏览器 localStorage，刷新不丢失

## 分层结构

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 资料 | `src/data/types.ts`、`src/data/seed.ts` | 类型定义、个案与示例数据 |
| 判断 | `src/domain/practice.ts` | 纯函数规则：完成判定、排期冲突、漏交 streak、调整留痕、汇总 |
| 本机保存 | `src/storage/local.ts` | localStorage 读写，失败时静默降级 |
| 页面 | `src/App.tsx`、`src/styles.css` | 跟进台 UI 与交互 |
